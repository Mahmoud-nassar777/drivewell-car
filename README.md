# DriveWell — Premium Car Rental Experience 🚗

A modern and immersive car rental website designed to make exploring and choosing your next ride a smooth experience.

Built with React, Vite, Tailwind CSS, and React Three Fiber, featuring a clean interface, interactive elements, and a 3D vehicle showcase.

## ✨ Features

- Modern and responsive user interface.
- Premium vehicle categories and service sections.
- Interactive car cards and vehicle information.
- Smooth scroll-based reveal animations.
- Custom horizontal scrolling experience.
- Interactive 3D vehicle showcase.
- 3D model interaction and vehicle color customization.
- Reusable React components.
- Organized and reusable mock vehicle data.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React | Building the user interface |
| Vite | Development environment and build tool |
| Tailwind CSS v4 | Styling and responsive layouts |
| React Router | Client-side navigation |
| Three.js | 3D rendering |
| React Three Fiber | Three.js integration with React |
| React Three Drei | 3D helpers and utilities |
| Lucide React | Interface icons |
| React Icons | Additional icons |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd drivewell-car-rental
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### 5. Build for production

```bash
npm run build
```
